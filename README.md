# Product Description Generator API

یک API مبتنی بر **FastAPI** برای تولید خودکار عنوان بهینه، توضیح کوتاه و کلمات کلیدی برای محصولات، با استفاده از مدل زبانی محلی **Ollama** (مدل `gemma3:1b`).

## ویژگی‌ها

- استخراج عنوان استاندارد و بهینه از عنوان خام محصول
- تولید توضیح کوتاه و جذاب (۳۵۰ تا ۴۵۰ کاراکتر) برای صفحه محصول
- تولید ۸ تا ۱۲ کلمه کلیدی مرتبط با محصول
- پردازش غیرهمزمان (Background Task) به همراه پیگیری وضعیت و درصد پیشرفت
- بررسی سلامت سرویس و اتصال به Ollama

## پیش‌نیازها

- Python 3.9 یا بالاتر
- [Ollama](https://ollama.com) نصب‌شده و در حال اجرا روی `localhost:11434`
- مدل `gemma3:1b` دانلود شده در Ollama:
  ```bash
  ollama pull gemma3:1b
  ```

## نصب

```bash
pip install fastapi uvicorn requests pydantic
```

## اجرای برنامه

```bash
uvicorn main:app --reload
```

پس از اجرا، مستندات تعاملی API در آدرس زیر در دسترس است:

```
http://localhost:8000/docs
```

## نقاط پایانی (Endpoints)

| متد | مسیر | توضیح |
|------|------|-------|
| `GET` | `/` | نمایش اطلاعات کلی API |
| `POST` | `/generate` | ایجاد درخواست جدید برای تولید محتوای محصول |
| `GET` | `/status/{request_id}` | بررسی وضعیت و درصد پیشرفت پردازش |
| `GET` | `/result/{request_id}` | دریافت نتیجه نهایی پردازش |
| `GET` | `/health` | بررسی سلامت API و اتصال به Ollama |

### نمونه استفاده

**۱. ارسال درخواست تولید محتوا:**

```bash
curl -X POST "http://localhost:8000/generate" \
  -H "Content-Type: application/json" \
  -d '{"text": "ماست کفی مهمان چربی کم چوب بسته بندی ۵۰۰ گرمی تولید ۱۴۰۳"}'
```

پاسخ شامل `request_id` است که برای پیگیری وضعیت استفاده می‌شود.

**۲. بررسی وضعیت پردازش:**

```bash
curl "http://localhost:8000/status/{request_id}"
```

**۳. دریافت نتیجه نهایی:**

```bash
curl "http://localhost:8000/result/{request_id}"
```

## نحوه عملکرد داخلی

پردازش هر درخواست در سه مرحله و به‌صورت غیرهمزمان در پس‌زمینه انجام می‌شود:

1. **استخراج عنوان** — تبدیل عنوان خام به عنوانی کوتاه، استاندارد و بدون اطلاعات زائد
2. **تولید توضیح کوتاه** — نگارش توضیحی جذاب و مناسب فروشگاه اینترنتی
3. **تولید کلمات کلیدی** — استخراج کلمات کلیدی اصلی، ثانویه و مرتبط با برند

نتایج هر درخواست به‌صورت موقت در حافظه (`processing_results`) نگهداری می‌شود.
